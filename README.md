# 🎓 EduTrack ERP Portal

A modern and responsive **Student ERP / Parent Monitoring Portal** built using:

- HTML
- CSS
- JavaScript
- Chart.js
- Font Awesome

This project allows parents and teachers to monitor:

✅ Attendance  
✅ Student Marks  
✅ Performance Analytics  
✅ Notifications  
✅ Student Profile  
✅ ERP Dashboard
